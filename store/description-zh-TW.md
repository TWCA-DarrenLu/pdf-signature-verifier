# PDFtrust - PDF 數位簽章驗證工具

在瀏覽器開啟 PDF 就自動驗證數位簽章。檔案不上傳，驗證在本機完成。

- 開啟即驗證：結果顯示在側邊面板，工具列圖示標示 ✓ 可信／! 無法完整驗證／✗ 驗證失敗
- 台灣憑證：預設信任政府憑證總管理中心體系與民間憑證機構，不接受自簽憑證
- 國際憑證機構：可在設定中選擇開啟
- 完整檢查：文件完整性、憑證鏈、撤銷狀態（OCSP／CRL）、RFC 3161 時戳、長期驗證（LTV）
- 法規標示：標示發行機構是否為電子簽章法許可之憑證機構
- 拖放或按右鍵即可驗證，可匯出 PDF 驗證報告

隱私：PDF 不會上傳；查詢撤銷狀態時只送出憑證識別資訊，不傳送文件內容。

支援繁體中文與英文。
