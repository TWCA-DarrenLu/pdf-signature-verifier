# PDFtrust - PDF 數位簽章驗證工具

在瀏覽器開啟 PDF 就自動驗證數位簽章 — 檔案不上傳，驗證在本機完成。預設信任台灣公部門與民間憑證，支援時戳與長期驗證（LTV）。

## 功能特色

- **開啟即驗證** — 在瀏覽器開啟 PDF 時自動驗證，結果顯示在側邊面板（Chrome、Edge）；可設定為所有網站、僅指定網站或關閉
- **工具列狀態** — 擴充功能圖示直接標示 ✓ 文件可信／! 無法完整驗證／✗ 驗證失敗，點一下看詳細結果
- **台灣 PKI 信任清單** — 公部門：政府憑證總管理中心（GRCA）體系的自然人憑證（MOICA）、政府機關憑證（GCA）、組織及團體憑證（XCA）、工商憑證（MOEACA）；民間：TWCA、中華電信。不接受自簽憑證
- **國際精選憑證機構（選用）** — 預設只信任台灣憑證；可在設定開啟 DigiCert、GlobalSign、Sectigo、IdenTrust、SSL.com 的文件簽章與時戳根憑證
- **法規標示** — 先驗證憑證鏈，再標示發行機構是否為電子簽章法許可之憑證機構；國際憑證標示為「非我國許可之憑證機構」
- **完整性驗證** — 確認文件在簽署後未被竄改，並偵測簽署後不允許的增修
- **憑證鏈與撤銷狀態** — 逐層驗證憑證鏈，以 PDF 內嵌或線上的 OCSP／CRL 確認憑證未被撤銷
- **時戳與 LTV** — 驗證 RFC 3161 時戳（須由台灣 PKI 時戳單位簽發），以時戳時間判斷已過期的憑證，並檢查長期驗證資料是否完整
- **清楚的結果** — 每項檢查以綠／紅／黃／灰標示；無法完整驗證時列出主要原因，可一鍵重新檢查
- **多種驗證方式** — 拖放 PDF 到通知列或擴充功能視窗、在連結上按右鍵「驗證此 PDF 的數位簽章」、網頁 PDF 連結旁的驗證按鈕
- **本機檔案** — 在擴充功能詳細資料開啟「允許存取檔案網址」後，本機 PDF 也會自動驗證
- **報告匯出** — 匯出完整的 PDF 驗證報告

## 使用方式

1. 在瀏覽器開啟 PDF，驗證自動開始
2. 在側邊面板或點工具列圖示查看結果，包括憑證鏈、時戳與撤銷狀態
3. 需要時重新檢查，或匯出驗證報告

## 隱私保護

PDF 檔案不會上傳到任何伺服器，驗證在瀏覽器本機進行。查詢撤銷狀態時，只會向憑證發行機構的 OCSP／CRL 服務查詢憑證狀態，不會傳送文件內容；查詢結果會短暫暫存，以減少重複連線。

## 支援的簽章格式

- CMS / PKCS#7（adbe.pkcs7.detached、adbe.pkcs7.sha1）
- RSA、ECDSA、RSA-PSS 簽章演算法
- SHA-256、SHA-384、SHA-512、SHA-1 雜湊演算法
- PAdES（PDF 進階電子簽章）

## 語言支援

繁體中文及英文。自動偵測瀏覽器語言，亦可在設定中手動切換。
